HTML5 Elements

Reference list of HTML5 elements organized by role, with example usage and a short description for each category.

Document metadata

These elements belong in the head and define document settings, resources, or scripts.

<html>
<html lang="en">...</html>

The root element for an HTML document; the lang attribute sets the document language. Best use case: Use as the root element of every HTML document to declare the document type and language.

<head>
<head><title>My Page</title></head>

Contains metadata, links to styles, scripts, and other information for the browser. Best use case: Use to group metadata, links, and scripts needed by the browser before rendering content.

<title>
<title>My Title</title>

Specifies the document title shown in the browser tab or search results. Best use case: Use to set the page title that appears in browser tabs and search engine results.

<base>
<base href="/docs/">

Defines the base URL for all relative URLs in the document. Best use case: Use when you need a common base URL for all relative links across the page.

<link>
<link rel="stylesheet" href="styles.css">

Links external resources such as stylesheets or icons to the document. Best use case: Use to attach external stylesheets, fonts, or icons to the page.

<meta>
<meta charset="UTF-8">

Provides metadata about the document, like character encoding or viewport settings. Best use case: Use to provide document metadata such as charset, viewport, or SEO information.

<style>
<style>body{margin:0}</style>

Contains CSS rules directly inside the HTML document. Best use case: Use for small amounts of page-specific CSS inside the document.

<script>
<script>console.log('Hi')</script>

Includes or references JavaScript code used by the page. Best use case: Use to add or load JavaScript behavior and interactivity.

<noscript>
<noscript>Enable JavaScript.</noscript>

Displays content when JavaScript is disabled in the browser. Best use case: Use to show fallback content when JavaScript is disabled.

<template>
<template><div>Card</div></template>

Holds HTML markup for cloning and reusing later with JavaScript. Best use case: Use to define HTML fragments that are cloned and inserted by JavaScript.

<slot>
<slot name="title"></slot>

Defines a placeholder inside a web component for projected content. Best use case: Use inside web components to mark where user-provided content is inserted.

Content sectioning

Use these elements to structure content into sections, navigation, and page regions.

<body>
<body>Page content</body>

Contains all visible page content and interactive elements. Best use case: Use to wrap all visible page content and interface elements.

<section>
<section><h2>Intro</h2></section>

Defines a thematic grouping of content with its own heading. Best use case: Use to group related content into a semantic section with its own heading.

<nav>
<nav><a href="#home">Home</a></nav>

Represents a navigation block with links to sections of the site. Best use case: Use to wrap main navigation links or menus for the page.

<article>
<article><h2>News</h2></article>

Represents an independent, self-contained piece of content. Best use case: Use for self-contained content that could be distributed independently.

<aside>
<aside>Sidebar info</aside>

Holds related content such as sidebars, pull quotes, or complementary info. Best use case: Use for content related to the main text, like sidebars or notes.

<header>
<header><h1>Title</h1></header>

Represents introductory content or navigation controls for a section. Best use case: Use for introductory content or controls at the top of a section.

<footer>
<footer>Site footer</footer>

Contains footer content like copyrights, links, or author info. Best use case: Use for closing content such as credits, links, or legal text.

<address>
<address>Contact us</address>

Contains contact information for the author or organization. Best use case: Use for author or site contact information in a footer or sidebar.

<main>
<main>Main content</main>

Designates the primary content area of the page. Best use case: Use to denote the document’s central content area for accessibility.

<div>
<div class="box">Box</div>

A generic container used to group content without meaning. Best use case: Use as a generic container when no semantic element fits better.

Text content

These tags are used for paragraphs, headings, lists, quotes, and text formatting.

<h1>– <h6>
<h1>Heading 1</h1><h2>Heading 2</h2>

Define six levels of headings for page structure and accessibility. Best use case: Use to structure the document hierarchy with meaningful headings.

<p>
<p>Paragraph text.</p>

Wraps a block of text as a paragraph. Best use case: Use for paragraphs of text and natural language content.

<hr>
<hr>

Inserts a thematic break between sections of content. Best use case: Use to separate sections visually or semantically on a page.

<br>
Line one.<br>Line two.

Creates a line break within text content. Best use case: Use to break a line only in text where new lines are needed.

<pre>
<pre>Preformatted text</pre>

Preserves whitespace and line breaks exactly as written. Best use case: Use for code snippets or text that requires preserved whitespace.

<blockquote>
<blockquote>Quote</blockquote>

Displays a section quoted from another source. Best use case: Use for longer quotations from external sources.

<ol>
<ol><li>One</li></ol>

Creates an ordered (numbered) list. Best use case: Use for ordered lists where sequence matters.

<ul>
<ul><li>One</li></ul>

Creates an unordered (bullet) list. Best use case: Use for unordered lists of related items.

<li>
<li>List item</li>

Defines an item inside an ordered or unordered list. Best use case: Use for each item inside ordered or unordered lists.

<dl>
<dl><dt>Term</dt><dd>Definition</dd></dl>

A description list of terms and details. Best use case: Use for term-definition pairs or property lists.

<dt>
<dt>Term</dt>

Defines a term in a description list. Best use case: Use for the term name in a description list.

<dd>
<dd>Definition</dd>

Provides the definition for a term. Best use case: Use for the definition or description of a term.

<figure>
<figure><img src="img.jpg"><figcaption>Caption</figcaption></figure>

Groups media content with a caption. Best use case: Use to group media with an optional caption.

<figcaption>
<figcaption>Image caption</figcaption>

Provides a caption for a figure element. Best use case: Use to describe or title the media contained in figure.

Inline text semantics

Use these elements to mark up text meaning, emphasis, and formatting.

<a>
<a href="https://example.com">Link</a>

Creates a hyperlink to another resource. Best use case: Use to create links that navigate to other pages or resources.

<em>
<em>Emphasized</em>

Marks text with emphasis, usually rendered italic. Best use case: Use to emphasize text that should be read with stress.

<strong>
<strong>Important</strong>

Marks strongly important text, usually rendered bold. Best use case: Use to indicate strong importance or urgency in text.

<small>
<small>Fine print</small>

Represents side comments and fine print. Best use case: Use for fine print, disclaimers, or legal notes.

<s>
<s>Strikethrough</s>

Shows text that is no longer accurate or relevant. Best use case: Use to represent text that is no longer accurate or relevant.

<cite>
<cite>Source name</cite>

Represents a creative work title or reference. Best use case: Use to cite a creative work or reference source.

<q>
<q>Short quote</q>

Represents an inline quotation. Best use case: Use for short inline quotations within text.

<dfn>
<dfn>HTML</dfn> definition.

Marks the defining instance of a term. Best use case: Use to mark the first use of a term being defined.

<abbr>
<abbr title="HyperText Markup Language">HTML</abbr>

Represents an abbreviation or acronym. Best use case: Use to show an abbreviation or acronym with its full form.

<data>
<data value="42">Answer</data>

Links a machine-readable value with human-readable text. Best use case: Use to attach machine-readable values to human-readable text.

<time>
<time datetime="2026-08-07">August 7, 2026</time>

Represents a date or time value. Best use case: Use to mark dates or times in a machine-readable format.

<code>
<code>const x = 3;</code>

Represents a fragment of computer code. Best use case: Use for inline code fragments or programming text.

<var>
<var>x</var> value.

Represents a variable or placeholder. Best use case: Use to represent variables or placeholders in code examples.

<samp>
<samp>Sample output</samp>

Represents sample output from a program. Best use case: Use for sample output from a program or system.

<kbd>
<kbd>Ctrl+C</kbd>

Represents user input from a keyboard, voice, or other device. Best use case: Use to represent user input like keys or commands.

<sub>
H<sub>2</sub>O

Displays text as subscript. Best use case: Use for scientific notation or chemical formulas.

<sup>
10<sup>2</sup>

Displays text as superscript. Best use case: Use for exponents or footnote markers.

<i>
<i>Italic text</i>

Represents text in an alternate voice or mood. Best use case: Use for terms in an alternate voice or technical text.

<b>
<b>Bold text</b>

Represents text without added importance or emphasis. Best use case: Use for stylistic text without additional importance.

<u>
<u>Underline</u>

Represents a text span with an unarticulated, non-textual annotation. Best use case: Use to underline text for non-semantic annotations.

<mark>
<mark>Highlighted</mark>

Highlights text for reference or emphasis. Best use case: Use to highlight text of special relevance.

<bdi>
<bdi>RTL text</bdi>

Isolates text direction to support bidirectional text. Best use case: Use to isolate bidirectional text in mixed-language content.

<bdo>
<bdo dir="rtl">Right-to-left</bdo>

Overrides the current text direction. Best use case: Use to explicitly override text direction.

<span>
<span class="label">Tag</span>

A generic inline container for styling or scripting. Best use case: Use as an inline wrapper for styling or scripting parts of text.

<wbr>
LongWord<wbr>Break

Suggests a line break opportunity within long text. Best use case: Use to suggest a line break point in long words.

<ins>
<ins>Added text</ins>

Represents inserted text, often used in revisions. Best use case: Use to mark inserted text in revision histories.

<del>
<del>Removed text</del>

Represents deleted text from a document. Best use case: Use to mark deleted text in revisions or updates.

Embedded content

Elements used to embed images, media, graphics, or interactive content.

<picture>
<picture><source srcset="image.webp" type="image/webp"><img src="image.jpg" alt="Photo"></picture>

Provides responsive image sources for different resolutions or formats. Best use case: Use for responsive images with multiple source formats.

<source>
<source srcset="image.webp" type="image/webp">

Specifies media resources for picture, audio, or video elements. Best use case: Use to provide different media sources for picture/audio/video.

<img>
<img src="photo.jpg" alt="Photo">

Displays an image in the document. Best use case: Use to embed images with meaningful alt text for accessibility.

<iframe>
<iframe src="https://example.com"></iframe>

Embeds another webpage or content within the current page. Best use case: Use to embed full webpages or external widgets securely.

<embed>
<embed src="file.pdf" type="application/pdf">

Embeds external content like PDFs or multimedia players. Best use case: Use to embed external resources like PDFs or plugins.

<object>
<object data="file.pdf" type="application/pdf"></object>

Embeds a resource and can include fallback content. Best use case: Use to embed content with fallback HTML inside the tag.

<param>
<object data="movie.swf"><param name="autoplay" value="true"></object>

Defines parameters for embedded objects. Best use case: Use with object to pass parameters to the embedded resource.

<video>
<video controls><source src="video.mp4" type="video/mp4"></video>

Embeds a video player with optional controls. Best use case: Use to include video playback with native controls.

<audio>
<audio controls><source src="audio.mp3" type="audio/mpeg"></audio>

Embeds audio with playback controls. Best use case: Use to include audio playback, music, or podcasts.

<track>
<video controls><track kind="captions" src="captions.vtt" srclang="en"></video>

Defines timed text tracks for media elements. Best use case: Use to add captions or subtitles to video/audio media.

<map>
<map name="map1"><area shape="rect" coords="0,0,100,100" href="#"></map>

Defines an image map with clickable areas. Best use case: Use to define an image map with clickable regions.

<area>
<area shape="rect" coords="0,0,100,100" href="#">

Defines a clickable region within an image map. Best use case: Use to declare active regions within an image map.

<canvas>
<canvas width="300" height="150"></canvas>

Creates a drawing surface for graphics rendered with JavaScript. Best use case: Use for dynamic graphics and animations with JavaScript.

<svg>
<svg width="100" height="100"><circle cx="50" cy="50" r="40"/></svg>

Defines scalable vector graphics directly in HTML. Best use case: Use for scalable vector graphics and icons.

<math>
<math><mi>x</mi></math>

Represents mathematical notation and formulas. Best use case: Use for mathematical expressions in web content.

<th>

<form action="/submit" method="post">...</form>

Wraps controls that collect and submit user input. Best use case: Use to collect user input and submit it to a server.

<fieldset>
<fieldset><legend>Info</legend></fieldset>

Groups related controls in a form. Best use case: Use to group related form controls for clarity.

<legend>
<legend>Form title</legend>

Labels a fieldset with a caption. Best use case: Use to label the grouped controls within a fieldset.

<label>
<label>Name<input></label>

Labels a form control for accessibility. Best use case: Use to make form controls accessible with text labels.

<input>
<input type="text" name="name">

Creates a control for textual or other types of user input. Best use case: Use to collect user input like text, email, or passwords.

<button>
<button type="submit">Send</button>

Represents a clickable button, often used to submit forms. Best use case: Use for actions such as submitting or resetting forms.

<select>

<datalist>

<optgroup>

<option>

<textarea>

<output>

<progress>
