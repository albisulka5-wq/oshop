Introduction

Java is a class-based, object-oriented programming language developed by James Gosling at Sun Microsystems in 1995. It is simple, readable, and helps developers write reusable code.

  • Mobile applications.
  • Desktop applications.
  • Web applications.
  • Database connections.
  • Games.
Syntax

The Java program flow is simple:

  • Create the file with your code.
  • Compile with javac HelloWorld.java.
  • Run it with java HelloWorld.

First Java example:

System.out.println("Hello World!");
Comments

Comments improve readability and can help explain code.

  • Single-line comments use //.
  • Multi-line comments use /* ... */.
Variables

Variables store data used by your program.

int age = 25; String name = "Alice";
Data Types

Java has primitive and reference types. Primitive ones include int, double, boolean, and char.

int score = 90; double price = 25.99; boolean isActive = true;
Type Casting

Type casting converts one data type into another when needed.

double x = 9.78; int y = (int) x;
Operators

Java supports arithmetic, relational, logical, and assignment operators.

int total = 10 + 5; boolean check = (a > b) && (c == d);
If else Statement

Decision-making is done with if, else if, and else statements.

if (age >= 18) { System.out.println("Adult"); } else { System.out.println("Minor"); }
Switch

Switch statements help test one variable against multiple values.

switch (day) { case 1: System.out.println("Monday"); break; default: System.out.println("Other"); }
While Loop

A while loop runs as long as the condition remains true.

int i = 0; while (i < 5) { System.out.println(i); i++; }
For Loop

A for loop is useful when you know how many times you want to repeat code.

for (int i = 0; i < 5; i++) { System.out.println(i); }
Break Continue

Break stops the loop, while continue jumps to the next iteration.

for (int i = 0; i < 10; i++) { if (i == 5) continue; if (i == 8) break; System.out.println(i); }
Arrays

Arrays store multiple values of the same type in one variable.

int[] numbers = {1, 2, 3, 4}; System.out.println(numbers[0]);
OOP

Object-Oriented Programming organizes code into classes and objects.

Classes

A class is a blueprint for creating objects.

class Car { String model; }
Constructors

Constructors initialize new objects when they are created.

class Student { Student() { System.out.println("Created"); } }
Encapsulation

Encapsulation hides data and exposes controlled access through methods.

Inheritance

Inheritance lets a class reuse behavior from a parent class.

class Animal { void eat() {} } class Dog extends Animal { }
Polymorphism

Polymorphism allows the same method name to act differently depending on the object.

Abstraction

Abstraction hides unnecessary details and exposes only essential behavior.

Reference

References point to objects in memory and allow interaction with them.

String name = new String("Alice");
